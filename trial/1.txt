### 4. Hot Chips 2026: Arm Dissects 136-Core AGI Server CPU with 2 TB/s UCIe Interconnect and Monolithic SoC Chiplets (Category 6)

**Source:** Hot Chips 2026 Technical Proceedings / Tom's Hardware / ServeTheHome / MLQ.ai  
**Event Date:** 2026-08-25 (Presented at Stanford University)  
**Source Date:** 2026-08-26 / 2026-08-27 (Detailed Technical Architecture Published)  
**Status:** Conference Technical Proceedings & Server Microprocessor Architecture  
**Primary URL:** https://www.tomshardware.com/pc-components/cpus/hot-chips-2026-arm-details-agi-server-cpu  

#### [Overview]
Why this microprocessor architecture matters: In agentic artificial intelligence servers, host CPUs are responsible for managing complex multi-turn orchestration loops, scheduling dynamic tool calls, compiling intermediate code, and managing multi-gigabyte context caches across memory pools. Traditional server CPU designs (such as AMD EPYC or Intel Xeon) separate compute dies from a centralized I/O die, introducing inter-die routing latency that degrades single-thread execution responsiveness during memory-bound agentic operations.

At the Hot Chips 2026 Symposium (Stanford University), Arm detailed the complete silicon architecture of its **AGI data center CPU**—the company’s first complete in-house commercial processor design, developed with lead partner **Meta** and targeted for production shipments in late 2026. Rather than using separate I/O dies, Arm implemented a dual-chiplet architecture where each self-contained SoC die is fabricated on **TSMC’s advanced N3P process node**. Each CSS V3 chiplet integrates 50 billion transistors, housing 70 Neoverse V3 cores (four reserved for yield recovery, enabling up to **136 active physical cores per socket**), a six-channel DDR5 memory controller, and native I/O. The two chiplets communicate across an ultra-dense **16x16 UCIe (Universal Chiplet Interconnect Express) array running at 32 GT/s**, delivering **2 TB/s of aggregated die-to-die bandwidth**. By integrating memory controllers and PCIe/CXL logic directly on the compute dies, Arm achieves **sub-100ns DRAM access latency** and up to **844.8 GB/s of aggregate memory bandwidth** across 12 channels of DDR5-8800 (supporting up to 6TB per socket) within a highly efficient **300W Thermal Design Power (TDP)**.

Impact on physical board, package, signal integrity (SI), and power delivery (PI):
1. **UCIe Die-to-Die Interconnect & Substrate Routing:** Routing a 16x16 UCIe array at 32 GT/s across standard organic package substrates requires sub-micron bump pitch alignment and micro-via precision to preserve signal eye-margins and suppress high-frequency crosstalk across the 2 TB/s bridge.
2. **Sub-100ns Memory Subsystem & Signal Integrity:** Driving 12 channels of DDR5-8800 across high-layer-count server motherboards demands ultra-low-loss PCB laminates and strict serpentine trace length matching to mitigate channel insertion loss.
3. **Point-of-Load Power Delivery (PI):** Delivering stable current to 136 wide-decode cores (10-wide dispatch/decode) bursting simultaneously during agentic compilation tasks requires high-bandwidth multi-phase VRMs with low equivalent series resistance (ESR) decoupling capacitors positioned directly underneath the socket substrate to eliminate transient voltage droop (di/dt) within the 300W power envelope.

#### [Strategic Impact]

- **Technology & Ecosystem Perspective:** Validates the UCIe open standard for high-bandwidth, low-latency multi-chiplet server silicon, offering a modular template for hyperscaler custom SoC designs.
- **Business & Market Dynamics:** Positions Arm to capture high-margin host CPU sockets in hyperscale AI datacenters, directly challenging traditional x86 server dominance across orchestration nodes.
- **Infrastructure & Hardware Implications:** Delivers high memory bandwidth (844.8 GB/s) and sub-100ns DRAM latency within an air-cooled 300W envelope, maximizing rack compute density.
- **Investment Strategy:** Overweight advanced semiconductor substrate manufacturers, UCIe IP design providers (Alphawave Semi), and enterprise server OEMs (Supermicro, Lenovo, ASRock Rack).

#### [Technical Deep Dive]

- **Core Technical Specifications:**
  - Processor Architecture: Arm AGI Data Center CPU (Arm Neoverse V3 Core Complex)
  - Silicon Topology: Dual Monolithic SoC Chiplets (TSMC N3P Process Node, >100B Transistors Total)
  - Core Count & Frequency: 64, 128, or 136 Active Cores (70 Cores per chiplet with 4 redundant cores for yield); 2.80 GHz base to 3.70 GHz boost
  - Microarchitecture: 10-wide frontend/decode, 10-wide dispatch, 8-wide retire, 384+ entry Out-of-Order (OoO) execution window, dual 128-bit vector engines
  - Cache Hierarchy: 2MB private L2 cache per core; up to 272MB System-Level Cache (SLC) across socket
  - Die-to-Die Interconnect: 16x16 UCIe Macro Array @ 32 GT/s delivering 2.0 TB/s Aggregated Interconnect Bandwidth
  - Memory Subsystem: 12 DDR5 Channels (6 channels per chiplet) supporting DDR5-8800, up to 6TB capacity per socket; 844.8 GB/s peak memory bandwidth with sub-100ns latency
  - I/O & Expansion: 96 PCIe Gen 6.0 lanes with native CXL 3.0 protocol support; 4 PCIe Gen 4.0 lanes
  - Thermal Envelope: 300W Base Thermal Design Power (TDP)
  - Primary Source: Hot Chips 2026 Proceedings / Tom's Hardware / Arm Technical Disclosures (2026-08-26)
- **Comparative Analysis:** Unlike AMD Zen 5 (EPYC Turin) and Intel Xeon (Diamond Rapids), which route memory access through dedicated I/O dies or interposers, Arm's integrated SoC chiplets keep memory controllers adjacent to compute cores, achieving lower access latency critical for dynamic agent orchestration.
- **Deployment Status:** Silicon validated; lead systems sampling to Meta, OpenAI, and Cloudflare; commercial production deliveries scheduled for late 2026 via Supermicro, Lenovo, and ASRock Rack.

#### [Critical View]
While Arm’s integrated SoC approach delivers sub-100ns memory latency, fabricating complete memory controllers and PCIe I/O physical layers directly on advanced TSMC N3P silicon increases die manufacturing costs compared to offloading I/O to mature, inexpensive process nodes (such as 6nm or 12nm).
