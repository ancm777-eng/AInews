Why this infrastructure financing structure matters: In frontier artificial intelligence scaling, access to energized high-voltage datacenter real estate has emerged as the primary physical constraint. Under the multi-tier structured arrangement, **Nvidia serves as the primary master lessee, holding the direct 15-year facility leases** with site developer Hut 8 (part of a broader $19.6 billion base-term lease commitment across Hut 8's 704 MW Texas campus). ### 4. Hot Chips 2026: Arm Details 136-Active-Core AGI Server CPU with 2 TB/s UCIe Interconnect and Dual Monolithic N3P Chiplets (Category 6)

**Source:** Hot Chips 2026 Technical Proceedings / Tom's Hardware / ServeTheHome / Arm Technical Publications  
**Event Date:** 2026-08-25 (Hot Chips 2026 Presentation)  
**Source Date:** 2026-08-26 (Detailed Microarchitectural Analysis Published)  
**Status:** Peer-Reviewed Conference Technical Presentation & Silicon Architecture  
**Primary URL:** https://www.tomshardware.com/pc-components/cpus/hot-chips-2026-arm-details-agi-server-cpu-with-two-70-core-n3p-chiplets  

#### [Overview]
Why this server CPU architecture matters: In agentic artificial intelligence clusters, host CPUs perform heavy orchestration: maintaining conversational state across hundred-thousand-token contexts, compiling dynamic code, scheduling tool APIs, and shuttling data between system memory and accelerator clusters. Conventional multi-chiplet server processors route memory traffic through a centralized I/O die (IOD), adding interconnect hops and memory latency that constrain memory-bound orchestration workloads.

At the Hot Chips 2026 Symposium (Stanford University), Arm presented the complete microarchitecture of its **AGI data center CPU**, designed for hyperscale AI orchestration nodes and on track for commercial shipments starting in late 2026. Arm departed from the separate I/O die paradigm by utilizing a dual-chiplet architecture where each monolithic SoC die is fabricated on **TSMC’s N3P node**. Each Compute Subsystem (CSS) chiplet integrates 50 billion transistors, housing 70 Neoverse V3 cores, an integrated six-channel memory controller, and native PCIe/CXL physical layers. Across the package, **4 cores out of the 140 physical cores (2 cores per chiplet) are reserved for silicon yield recovery, delivering up to 136 active physical cores per socket**. The two dies communicate across a **16x16 UCIe (Universal Chiplet Interconnect Express) macro array running at 32 GT/s, delivering 2.0 TB/s of aggregate bidirectional bandwidth (~1.0 TB/s per direction)**. By co-locating the 12-channel DDR5-8800 subsystem directly on the compute dies, the processor achieves **844.8 GB/s of peak theoretical memory bandwidth with sub-100ns direct DRAM access latency** within a **300W Thermal Design Power (TDP)**.

System-level impact on package, signal integrity (SI), power integrity (PI), and motherboard design:
1. **UCIe Die-to-Die Routing & Package SI:** Routing 256 physical differential channels across a 16x16 UCIe array at 32 GT/s on advanced organic substrate packaging requires precise sub-micron die-placement alignment accuracy (with standard tens-of-microns micro-bump pitch) to control trace impedance variations and maintain signal eye margins across the die-to-die bridge.
2. **High-Speed Memory Bus & Board SI:** Operating 12 channels of DDR5-8800 (6 channels per chiplet, supporting up to 6TB per socket) requires high-layer-count server motherboards using ultra-low-loss dielectric laminates (e.g., Megtron-8 class) and strict serpentine trace length matching to prevent high-frequency insertion loss and crosstalk.
3. **Point-of-Load Transient Power Delivery (PI):** Powering 136 wide-decode cores (10-wide decode/dispatch, 384+ entry OoO window) during synchronized burst transitions requires multiphase voltage regulator modules (VRMs) and ultra-low equivalent series resistance (ESR) multi-layer ceramic capacitors (MLCCs) positioned directly beneath the BGA socket on the board backside to suppress high di/dt transient voltage droop.

#### [Strategic Impact]

- **Technology & Ecosystem Perspective:** Demonstrates production implementation of the UCIe open standard for high-bandwidth, low-latency multi-chiplet server silicon, providing a standard reference model for custom datacenter SoCs.
- **Business & Market Dynamics:** Positions Arm to capture high-value host CPU sockets in hyperscale AI datacenters, providing an alternative to traditional x86 server microprocessors for agent orchestration nodes.
- **Infrastructure & Hardware Implications:** Delivers 844.8 GB/s memory bandwidth and sub-100ns DRAM latency within an air-coolable 300W envelope, optimizing thermal budgets and server rack density.
- **Investment Strategy:** Overweight advanced semiconductor substrate suppliers, UCIe interface IP providers, and enterprise server OEMs integrating Arm Neoverse CSS platforms.

#### [Technical Deep Dive]

- **Core Technical Specifications:**
  - Processor Architecture: Arm AGI Data Center CPU (Arm Neoverse CSS V3 Platform)
  - Silicon Topology: Dual Monolithic SoC Chiplets (TSMC N3P Process Node, ~100B Total Transistors)
  - Physical Core Topology: 140 Physical Cores Total (70 Cores per chiplet); 4 cores per socket reserved for yield redundancy, enabling 136 active cores per socket (configurable in 64, 128, or 136 active core SKUs)
  - Core Frequencies: 2.80 GHz Base / 3.70 GHz Boost
  - Microarchitecture: 10-wide decode, 10-wide dispatch, 8-wide retire, 384+ entry Out-of-Order (OoO) window, dual 128-bit vector execution pipelines
  - Cache Architecture: 2MB private L2 cache per core (272MB total L2 across 136 cores), complemented by shared System-Level Cache (SLC)
  - Die-to-Die Interconnect: 16x16 UCIe macro array @ 32 GT/s delivering 2.0 TB/s aggregate bidirectional bandwidth (~1.0 TB/s per direction)
  - Memory Subsystem: 12 DDR5 channels (6 channels per chiplet) supporting DDR5-8800 and up to 6TB per socket; 844.8 GB/s peak theoretical memory bandwidth with sub-100ns DRAM latency
  - High-Speed Expansion I/O: 96 lanes PCIe Gen 6.0 with CXL 3.0 protocol support, plus 4 lanes PCIe Gen 4.0
  - Thermal Envelope: 300W Base Thermal Design Power (TDP)
  - Primary Source: Hot Chips 2026 Proceedings / Tom's Hardware / ServeTheHome (2026-08-26)
- **Comparative Analysis:** While AMD EPYC Turin utilizes separate Core Complex Dies (CCDs) routed through a centralized I/O die on an organic package substrate, Arm's dual monolithic SoC dies place memory controllers directly on the compute silicon, lowering memory access latency for agentic orchestration loops.
- **Deployment Status:** Silicon validated; customer sampling underway, with commercial server availability scheduled for late 2026.

While integrating memory controllers and high-speed SerDes (serializer/deserializer) I/O directly onto TSMC N3P compute silicon minimizes latency, it utilizes expensive cutting-edge lithography area for I/O circuits that do not scale down in area as efficiently as digital logic, increasing overall silicon wafer costs relative to disaggregated I/O die architectures.
