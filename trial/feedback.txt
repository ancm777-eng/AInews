## 2. 기사별 사실·논리 검토

### ① Shizuku-Duplex — 시간 단위와 성능 주장의 구분 필요

**확인 가능한 문제**

- **80ms 평가 주기는 종단 간 응답 지연 80ms와 다릅니다.**  
  본문은 “80ms마다 입력을 평가한다”고 설명하지만, 제목의 “80ms conversational voice architecture”는 실제 응답 지연으로 읽힐 수 있습니다.  
  → **“80ms 청크 단위로 동작하는 일본어 전이중 음성 프로토타입”**으로 표현하고, 최초 음성 출력 지연은 별도로 표시하십시오.

- **비동기 도구 호출이 GPU 메모리 절감을 자동으로 보장하지 않습니다.**  
  추론 모델을 분리하더라도 별도 서버의 모델 가중치·KV 캐시가 필요할 수 있습니다. “대형 추론 컨텍스트의 GPU 상주 필요를 제거한다”거나 “소형 가속기에서 결정적인 80ms 예산을 유지한다”는 결론에는 실제 배치 구성과 측정치가 필요합니다.

**원문 확인 필요**

- `https://shizuku.ai/blog/1/`의 실제 게시일·운영 주체
- Shizuku-Duplex의 정확한 명칭과 공개 상태
- 24kHz 출력, Live2D 동작 출력, 5분 요약 주기, 7.1초 검색 사례
- **79% 대 95%** 벤치마크의 문항 수·평가 조건·비교 모델
- **“GPT-Live”의 정확한 공식 제품명 또는 모델 ID**

**권고:** 연구 시연과 개발자 프리뷰를 구분하고, 자체 평가 수치는 “개발사 내부 평가”로 명시하십시오.

### ② llama-modchip — 압축 수치의 적용 범위와 실행 조건 보완 필요

**수치 검산**

- 76.87GiB → 56.56GiB는 **20.31GiB 감소, 약 26.42% 감소**로 산술상 맞습니다.
- 다만 **284.33B 전체 파라미터를 3.75비트로 저장하면 약 124.1GiB**입니다.
- 56.56GiB를 원래 284.33B 전체에 대응시키면 평균 약 **1.71비트/파라미터**입니다.

이는 곧바로 허위라는 뜻은 아닙니다. 초안처럼 **3.75비트가 MLA 등 일부 텐서에만 적용되고 다른 부분에 프루닝·별도 압축이 적용된다면** 양립할 수 있습니다. 하지만 현재 기술 설명과 Critical View는 이를 전체 모델의 “3.75-bit compression”처럼 혼용합니다.

**추가로 필요한 보완**

- **64GB와 64GiB를 구분해야 합니다.** 64GB를 십진 용량으로 해석하면 약 59.60GiB이므로, VmRSS 58.9GiB는 운영체제 등을 위한 여유가 매우 작습니다.
- **VmRSS만으로 “스와핑 없음”은 입증되지 않습니다.** 스왑 사용량, 메모리 매핑, 페이지 폴트, 측정 시점도 필요합니다.
- **“256K 지원”과 “실제 256K 입력을 처리한 상태의 메모리 측정”은 다릅니다.** KV 캐시 형식과 실제 사용 토큰 수를 명시해야 합니다.
- 비교표의 **“표준 OpenAI HTTP 루프는 45초 재평가”**는 일반적 속성이 아닙니다. 특정 구성에서 얻은 측정값이라면 그렇게 한정해야 합니다.
- “품질 저하가 불가피하다”는 문장 역시 벤치마크 없이 단정하지 않는 것이 적절합니다.

**원문 확인 필요**

GitHub 저장소의 존재·소유자·라이선스, `v2.4.0` 태그와 릴리스 시각, DeepSeek-V4-Flash 공식 구성, 커널 구현, 재현 명령, 각 처리량의 CPU·메모리·스레드 조건을 확인해야 합니다. 현재 저장소 상태만으로 **11월 8일 릴리스**를 증명할 수는 없습니다.

### ③ Galaxy Campus — 시간 예외는 유효하나, 설비 범위와 비용 기준을 분리해야 함

**시간 판정:** 제공된 메타데이터 기준으로 7일 예외가 적용됩니다. **11월 7일이라는 이유만으로 교체할 필요는 없습니다.**

**기술·분석 보완**

- **800V DC 배전이 중앙 냉동기 불필요를 직접 입증하지는 않습니다.**  
  전력 변환 손실과 냉각 설계는 관련은 있지만 별도 문제입니다. 냉동기 사용 여부는 수온, 외기 조건, 열교환 방식 등에 대한 근거가 필요합니다.
- **800V 배전이 서버 트레이 내부까지 직접 들어간다고 단정할 수 없습니다.**  
  랙·파워셸프·서버 입력 사이의 강압 위치를 확인한 뒤 SiC/GaN 수요를 논해야 합니다.
- **MW당 건설비는 비교 범위를 맞춰야 합니다.**  
  토지·계통 연결·발전·저장장치·냉각·IT 장비 포함 여부가 다르면 “미국의 5분의 1”이라는 결론이 왜곡될 수 있습니다.
- “전력 손실 두 자릿수 감소”는 **손실량의 상대 감소율인지, 효율의 퍼센트포인트 개선인지** 명확히 해야 합니다.

**원문 확인 필요**

특히 **가동 중인 120MW 전체에 적용된 설비인지, 일부 파일럿인지**를 구분하십시오. 현재 제목과 로드맵은 독자가 적용 범위를 혼동할 여지가 있습니다.
