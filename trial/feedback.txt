## 2. 기사별 사실·논리 점검

### ① TailSteer — 시간 부적합, 정량 주장 원문 대조 필요

**확정 문제**
- `event_date: 2026-11-06`과 `event_within_24h_window: true`는 KST 기준에서 서로 맞지 않습니다.
- “추가 추론 파라미터가 없다”는 사실만으로 **추론 지연 0%·추가 VRAM 0**이 입증되지는 않습니다. 기존 가중치를 유지하더라도 blending 연산, 중간 텐서, 캐시 등에 비용이 발생할 수 있습니다.

**원문 확인이 필요한 핵심**
- `arXiv:2611.06741`의 실제 제목·저자·소속과 TailSteer의 일치 여부.
- `FLUX.2 Klein Base 9B`, `Qwen-Image-2.1`, `SenseNova-U1.5-8B-MoT`, `GPT-Image-2.5 Sunburst`의 정확한 명칭과 논문 내 평가 여부.
- LPIPS **0.524→0.290**, 비편집 영역 **91.8%·48.2%**, 성능 유지 **1.2% 이내**, 시간 임계값 **0.3**의 표·절 번호.
- 코드와 체크포인트 각각의 공개 주소 및 라이선스. 코드의 Apache 2.0 라이선스를 기반 모델 가중치의 사용 조건과 동일시해서는 안 됩니다.

**보완**
- 비교표의 “Asymmetric Teacher-Forcing”에 붙인 메모리 조회·지연·VRAM 수치는 특정 구현과 측정 근거를 제시해야 합니다. 학습 방식 명칭만으로 해당 추론 비용이 정해지지는 않습니다.
- “Photoshop 대체”, “마스크 우회책 불필요”는 결과가 입증한 범위보다 넓은 표현입니다. **비편집 영역 보존 성능 개선**과 **레이어·마스크 기반 비파괴 편집 대체**를 분리하십시오.
- 소비자 GPU 구동 주장은 해상도·정밀도·양자화·오프로딩·최대 VRAM 측정을 함께 제시해야 합니다.

### ② Google–Crusoe — 시간 부적합, 거래 범위와 투자액 구분 필요

**확정 문제**
- 현재 사건일은 24시간 범위 밖입니다.
- **800V DC 랙 전력 배전이 지역 전력망 변압기 납기 문제를 우회한다는 설명은 인과관계가 부정확합니다.** 랙 내부 전력 변환 구조와 계통 접속·고압 변전설비는 서로 다른 계층입니다.
- 자체 발전은 계통 의존도를 낮출 수 있지만, 해당 현장의 접속·변전설비 요구가 사라지는지는 별도 확인이 필요합니다.

**원문 확인이 필요한 핵심**
- 제시한 Crusoe URL의 실제 존재 및 발표 내용.
- 거래 대상이 **토지·개발권·프로젝트 법인·전체 캠퍼스** 중 무엇인지.
- **170억 달러**가 해당 부지의 확정 투자액인지, 장기 계획인지, 다른 지역·사업을 포함한 총액인지.
- **1.8GW·10GW·716에이커**가 같은 개발 경계와 같은 시점의 계획을 가리키는지.
- GE Vernova 터빈, SOFC, 345/500kV 접속, 탄소 포집, 2031년 완공 일정이 실제 확정 사양인지.

**보완**
- “공랭식 외부 열교환”과 “직접 칩 액체냉각”은 양립 가능합니다. 문제는 그 자체가 아니라, 이를 **전체 시설의 물 소비 0**으로 확대 해석하는 부분입니다. “증발식 냉각용 물 사용 없음”과 “시설 총취수량 0”을 구분하십시오.
- “일정 마찰과 비용 상승 때문에 인수”, “독립 개발자의 자금조달 실패”는 거래 당사자나 신뢰할 만한 보도의 명시적 근거 없이는 원인으로 단정하지 않는 편이 적절합니다.
- 단계별 TPU 세대·전력·준공 일정은 공식 계획과 분석자의 추정을 표시해 분리하십시오.

### ③ OptIMerge — 현재 슬롯에서는 시간 부적합

**확정 문제**
- 학술 논문이라는 이유만으로 자동으로 7일 예외가 적용되지는 않습니다. 현재 메타데이터는 `slot_category: 1-5`이므로 24시간 기준을 위반합니다.
- 다만 실제 연구 내용과 편집 정책이 허용한다면 **연구 슬롯으로 재분류 가능한지** 검토할 수 있습니다. 이는 현재 메타데이터 그대로 통과한다는 뜻은 아닙니다.

**원문 확인이 필요한 핵심**
- `arXiv:2611.07543`의 제목·저자·Google Research 소속 일치 여부.
- Cayley 변환, attention 정렬 방식, **0.4% 미만**, **100~500장**, **4.2~6.8dB**, 단일 GPU 수분 내 수렴의 근거.
- 실제 평가 대상이 생성형 diffusion 모델인지, 복원 모델인지, 양쪽인지.
- Hugging Face diffusers 통합 일정이 저자 발표인지 초안 작성자의 예상인지.

**보완**
- 최적화 변수 비율이 0.4%라는 사실과 **배포 모델 메모리가 1.004배**라는 주장은 동일하지 않습니다. 변환을 가중치에 합칠 수 있는지, 추론 시 별도 보관하는지 확인해야 합니다.
- 제한된 복원 벤치마크 결과를 inpainting·색보정·커뮤니티 LoRA 전반으로 확장하려면 별도 실험 근거가 필요합니다.
- “공동 재학습을 불필요하게 만들었다”, “서로 다른 기반 모델 병합은 수학적으로 불가능하다”는 표현은 지나치게 단정적입니다. **이 방법의 검증 범위 밖**이라고 기술하는 것이 정확합니다.

### ④ Phantom — 시간 적합, 하드웨어 평가 조건 확인 필요

**시간 판정**
- 사건일 11월 5일은 허용된 7일 범위 안입니다. **오래된 기사라는 이유로 교체할 대상이 아닙니다.**

**원문 확인이 필요한 핵심**
- `arXiv:2611.06019`의 논문 제목, Duke·Qualcomm 저자 소속, NSF 지원 내역.
- **4.0배 속도 향상·5.5배 에너지 효율**의 비교 대상, 공정, 클럭, 메모리, 모델, 해상도 및 샘플링 단계 수.
- **활용률 90% 이상·FID 차이 0.04·FP8/INT8**의 실제 보고 여부.
- 평가가 사이클 정확 시뮬레이션인지, RTL 시뮬레이션인지, 합성 결과인지, 실측 칩 결과인지. 초안은 이들을 명확하게 구분하지 않습니다.

**보완**
- GPU와 NPU를 하나의 비교 기준처럼 쓰지 말고, 각 배율에 해당하는 baseline을 명시하십시오.
- “에너지 5.5배 절감”은 **에너지 소비가 기준의 약 18.2%, 약 81.8% 감소**인지 명료하게 적으십시오.
- FID 차이가 작다는 결과와 “품질 손실이 전혀 없다”는 주장은 다릅니다.
- VRM 전압 강하 완화, 스마트폰 열 스로틀링 제거는 직접 평가가 없다면 **잠재적 효과**로 낮춰 표현해야 합니다.
