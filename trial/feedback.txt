## 2. 항목별 사실 검증

### 항목 1 — NVIDIA Nemotron / RTX Spark

**판정: 하드웨어 설명 수정 필요. 모델 발표와 성능 수치는 원문 확인 보류.**

#### 확인 가능한 문제

**① GB10을 “20-core Grace Arm CPU”로 설명한 부분**

기존 공개된 DGX Spark의 GB10은 **20코어 Arm CPU와 Blackwell GPU를 통합한 칩**이며, CPU 구성은 **Cortex-X925 10개와 Cortex-A725 10개**입니다. 이를 NVIDIA Grace CPU와 동일하게 기술하면 제품 계열을 혼동하게 됩니다.

또한 기존 GB10 기반 제품인 **DGX Spark는 데스크톱 시스템**입니다. 새로 발표된 별도 제품이라는 근거 없이 GB10 사양을 “RTX Spark 노트북”의 사양으로 옮겨 쓸 수 없습니다.

**수정:** 새 RTX Spark 제품의 공식 제품 페이지와 데이터시트를 제시하고, DGX Spark·GB10·Grace를 분리해 설명해야 합니다.

**② GB300까지 이어지는 제품 혼용 위험**

이 항목은 다음을 하나의 검증된 구성처럼 결합하고 있습니다.

- 24GB에서 구동되는 모델
- 128GB 통합 메모리 GB10 시스템
- 노트북 플랫폼
- Microsoft 공동 개발
- 150W 미만 전체 시스템 전력

이 조합이 논리적으로 불가능한 것은 아닙니다. 그러나 **24GB 모델 점유량과 128GB 장치 용량은 서로 다른 수치**이며, 이를 근거로 24GB 노트북에서 동일한 성능과 컨텍스트를 보장할 수는 없습니다.

#### 산술 검산

74B 전체 가중치를 2.0625비트로 저장하면:

\[
74 \times 10^9 \times 2.0625 / 8
= 19.078125\ \text{GB}
\]

따라서 **가중치만 약 19.08GB**라는 계산은 가능합니다. 하지만 이 계산은 다음을 포함하지 않습니다.

- 비양자화 텐서와 보조 데이터
- 실행 버퍼
- KV 캐시 또는 상태 메모리
- 운영체제와 다른 애플리케이션

즉 **“24GB에서 실행 가능”은 산술적으로 배제되지 않지만, “OS와 함께 256K 컨텍스트까지 수용”한다는 결론은 나오지 않습니다.** 반대로 하이브리드 Mamba 구조라는 점을 무시하고 일반 Transformer의 KV 캐시 부담을 그대로 적용해서도 안 됩니다.

#### 출처 확인이 필요한 부분

- `Nemotron 3.5 Bolt 74B-A9B`, `Star Elastic`, `LiLiCorr`의 정확한 명칭과 공식 연결 관계
- 84 TPS의 장치·컨텍스트·배치·초안 모델 조건
- OpenMDW 1.1 라이선스
- 비교 모델의 정확한 버전과 PinchBench 순위
- 900GB/s NVLink-C2C 수치의 해당 제품 적용 여부

**URL 관련:** 제시된 VentureBeat 주소는 제목상 **“Nemotron 3.5 Super VL”**을 가리키지만 본문은 **“Bolt 74B-A9B”**를 다룹니다. 하나의 기사에서 두 제품을 다룰 수도 있으므로 URL 오류로 단정할 수는 없지만, 현재 상태로는 핵심 제품의 직접 근거가 불분명합니다.

**분석 보완:** “zero-latency”, “데이터센터를 영구적으로 떠날 수 있다”, “물리적 제약을 깨뜨렸다”는 표현은 삭제하거나 완화하십시오. 로컬 추론도 계산 지연이 있으며, 일부 워크로드의 로컬 실행 가능성이 클라우드 대체 전체를 입증하지는 않습니다.

### 항목 3 — 미국 8개 주의 OpenAI 소송

**판정: 제소 사실·주 명단은 확인 보류. 법적 효과를 단정한 서술은 수정 필요.**

#### 명확한 논리적 문제

초안은 소송 제기를 근거로 다음을 이미 확정된 결과처럼 설명합니다.

- “법적 방어막이 뚫렸다”
- “긴급한 법적 선례를 확립했다”
- 모든 추론 스트림에 안전 검증 계층을 “의무화한다”

그러나 **소송 제기는 판결·금지명령·합의가 아닙니다.** 원고의 청구만으로 새로운 법적 의무가 확정되거나 판례가 성립하지는 않습니다.

**권장 수정**
> 이번 제소는 소비자보호법상 책임 범위를 다투는 절차를 개시했다. 원고 측 청구가 인용되거나 합의에 반영될 경우, 연령 확인과 안전 감사 요건이 강화될 수 있다.

#### 확인이 필요한 부분

- 정확히 8개 주가 각각 제소했는지, 공동 소장을 제출했는지
- 기재된 주 명단
- 부모 동의 없는 데이터 수집 등 각 혐의의 실제 소장 포함 여부
- 공감 기능 비활성화·독립 감사가 실제 청구 구제인지
- 미국 소비자 생성형 AI 시장 점유율 **48%**의 조사기관·기간·분모

AP URL은 원문에 접속해 제목·발행 시각·본문을 확인해야 합니다. 주소 형태만으로 유효하거나 무효라고 판정할 수는 없습니다.

**분석 보완:** 소장에 적힌 주장은 “원고는 …라고 주장했다”로 귀속하십시오. 또한 기업용 AI나 주권 AI의 소비자 책임 노출이 “negligible”하다는 표현은 지나칩니다.

### 항목 4 — Microsoft Maia 300

**판정: 7일 윈도우 적합. GB300 비교표에 수정 가능한 오류 존재. Maia 300 세부 사양은 확인 보류.**

#### 확인 가능한 비교표 오류

**① GB300을 “Monolithic CoWoS-L”로 표기**

Blackwell GPU는 **두 개의 GPU 다이를 연결하는 구조**입니다. CoWoS-L은 패키징 기술이지 모놀리식 다이라는 뜻이 아닙니다.

**수정 예시:**  
`Dual-die Blackwell GPU / CoWoS-L advanced packaging`

**② GB300 메모리를 “HBM3e/HBM4 @ ~13.5 TB/s”로 표기**

공개된 GB300/B300 제품 사양은 **GPU당 288GB HBM3e, 약 8TB/s 메모리 대역폭**을 기준으로 합니다. HBM4와 13.5TB/s를 GB300의 일반 사양으로 적으면 다른 제품·세대의 수치를 혼합하게 됩니다. 별도 개정판을 뜻한다면 그 제품의 공식 근거가 필요합니다.

#### 산술적으로 맞는 부분

- \(96 \times 288\text{ GB}=27.648\text{ TB}\)
- \(96 \times18\text{ TB/s}=1.728\text{ PB/s}\)

따라서 **27.6TB와 1.7PB/s는 개별 칩 사양이 맞다는 조건에서 계산상 타당**합니다.

다만 이를 하나의 공유 **“메모리 풀”**처럼 부르는 것은 별도 검증이 필요합니다. 칩별 메모리 용량·대역폭의 합계가 단일 주소 공간이나 실제 통신 성능을 뜻하지는 않습니다.

#### 출처 확인이 필요한 부분

Reuters 기사와 Microsoft 기술 문서를 분리해 다음 수치를 확인해야 합니다.

- N2P 연산 다이·3nm I/O 다이
- HBM4 8개·288GB·18TB/s
- 272MB SRAM
- 랙당 96개·167kW
- 7배 처리량·40% 전력 효율
- 100만 개 배치·연간 100억 달러 지출 내재화

특히 **167kW 랙이라는 사실만으로 400V DC 전력망이 필수라고 결론 낼 수는 없습니다.** 전력 분배 방식은 별도의 설계 정보입니다.

또한 실제 공식 블록도가 없다면 현재 도식은 **“초안 작성자의 개념도”**라고 표시해야 합니다.
