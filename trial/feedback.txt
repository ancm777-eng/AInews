## 1. KST 시간 윈도우

기준 시각은 **2026년 10월 23일 09:09 KST**이며, 일반 기사에 적용되는 직전 24시간 범위는 다음과 같습니다.

> **2026년 10월 22일 09:09 ~ 10월 23일 09:09 KST**

- 네 기사 모두 `Event Date: 2026-10-22`만 있어 **시간 윈도우 충족을 확정할 수 없습니다.** KST 기준 22일 오전 09:09 이전 사건이면 범위를 벗어납니다.
- 원문 날짜가 미국·유럽 현지 날짜라면 시각과 시간대를 확인한 뒤 KST로 변환해야 합니다.
- 제공된 메타데이터에는 `slot_category: 6` 또는 `ongoing_story_exception: true`가 없어, 현재로서는 예외를 적용할 근거가 없습니다.
- **기사 3은 본문 사건일이 10월 22일인데 로드맵에는 Flint v1.0 출시일이 10월 21일로 기재돼 있습니다.** 최초 공개와 후속 발표를 구분해야 합니다. 실제 신규 사건이 22일의 별도 배포·통합이라면 그 사건을 제목과 본문 중심에 놓아야 합니다.

**판정:** 네 기사 모두 날짜 자체를 오류로 볼 수는 없지만, 정확한 공개 시각이 없어 시간 검증은 미완료입니다.

## 2. 기사별 검증

### [1] MOSS-Image Edit / ComfyUI PR #17296

**주제 적합성:** 이미지 편집 모델과 로컬 창작 워크플로우는 유효한 브리핑 주제입니다.

**확인되는 수치·표현 문제**

- **BF16 메모리 수치의 범위가 불명확합니다.** 초안대로 DiT가 5B, 텍스트 인코더가 9B라면, 두 모델의 BF16 가중치를 모두 GPU에 상주시킬 경우 가중치만 약 **28GB**입니다. 따라서 “비양자화 BF16 약 22.4GB”를 전체 파이프라인 상주 메모리로 해석하면 맞지 않습니다. CPU 오프로딩·순차 로딩·인코더 양자화를 사용했다면 명시해야 합니다.
- `42개 층 × 6개 타깃 × LoRA A/B 2개 = 504개 텐서`는 **산술적으로 일치**합니다. 다만 실제 어댑터가 이 구성을 사용하는지는 가중치 파일 확인이 필요합니다.
- “100% air-gapped”, “zero-dependency”는 모델과 실행 도구만으로 자동 보장되지 않습니다. 완전 오프라인 실행 조건 및 추가 의존성의 의미를 한정해야 합니다.

**원문 확인 필요**

제공된 [PR #17296](https://github.com/comfyanonymous/ComfyUI/pull/17296)의 실제 제목·병합 시각·변경 파일, v0.42.4 포함 여부, 모델 카드의 기반 모델과 라이선스를 대조해야 합니다. 특히 **“공개 후 9시간 내 병합”, “최대 4개 참조”, “Qwen3.5 9B”, “FLUX.2 small VAE”**는 각각 직접 근거가 필요합니다.

**권고:** “상업용 합성 파이프라인을 대체했다”보다 “일부 참조 기반 편집 워크플로우의 로컬 대안을 제공한다”로 범위를 좁히십시오. Photoshop·Firefly의 품질을 일괄적으로 “Poor”라 평가한 표도 동일 조건의 비교 실험 없이는 삭제하는 편이 적절합니다.

### [2] NVIDIA Cosmos 3 / Data Factory

**핵심 논리 문제**

초안은 다음을 사실상 동일하게 취급합니다.

> 물리 조건 입력 및 비평 모델의 점수화 → 뉴턴 역학 준수 검증 → 결정론적 물리 시뮬레이션

그러나 **생성 영상의 물리적 개연성을 평가·필터링하는 것과 물리 법칙 준수를 보장하는 것은 다릅니다.** 본문도 후반부에서 충돌 경계 드리프트와 누적 오류를 인정합니다. 따라서 “NVIDIA solved”, “deterministic simulation engine”, “physically verified”는 제시된 설명만으로 뒷받침되지 않습니다.

**원문 확인 필요**

제공된 [NVIDIA 블로그 URL](https://blogs.nvidia.com/blog/gtc-berlin-cosmos-world-models-physical-ai/)에서 다음을 각각 확인해야 합니다.

- Cosmos 3 및 **Cosmos 3 Nano Reasoner**라는 정확한 제품명
- Data Factory 블루프린트 5종의 실제 목록
- 공개 체크포인트·NIM 컨테이너 링크
- **2.1배 처리량**, **개발 주기 40% 단축**의 측정 조건과 출처
- Siemens·Nebius의 실제 도입 상태가 발표·시험·상용 배포 중 어느 단계인지

**권고:** 물리 엔진과의 결합이 확인되지 않는 한 “물리 조건부 영상 생성 및 개연성 필터링”으로 표현하십시오. 40% 단축은 특정 사례인지 일반적인 성능인지 구분해야 합니다.

### [3] Recursive SI Flint

**확인되는 내부 불일치**

- **출시일:** 상단 10월 22일과 로드맵 10월 21일이 불일치합니다.
- **하드웨어:** 개요의 “NVIDIA RTX Spark 64GB”와 기술 설명의 “RTX Pro 6000 Blackwell Server Edition”은 다른 명칭입니다. 동일 실험을 설명하는 것이라면 장비 정보를 통일해야 합니다. 제품명 자체의 정확성도 별도 확인이 필요합니다.
- **속도 지표:** “125+ tok/s”, “150+ tok/s”, “164.9 tok/s”, “110→9 tok/s”에 정밀도·문맥 길이·배치·런타임·프리필/디코딩 구분이 없습니다. 특히 마지막 수치를 곧바로 **KV-cache 프리필 병목의 증거**로 사용하는 것은 측정 단계 확인 없이 성립하지 않습니다.

**오류로 단정하면 안 되는 부분**

- SWE-bench Pro 점수가 Verified보다 높다는 사실만으로 오류라고 할 수는 없습니다. 서로 다른 평가셋·하네스의 결과일 수 있습니다.
- 다만 “독립 평가”, “공식 평가”, “50B 미만 SOTA”라는 표현은 각각 평가 제출 기록과 비교 범위가 필요합니다.

**원문 확인 필요**

[RecursiveSI/flint](https://huggingface.co/RecursiveSI/flint)의 모델 카드, `config.json`, 라이선스 파일, 평가 로그를 확인해야 합니다. 2027년 모델 로드맵과 추정 점수는 공식 출처가 없다면 삭제하십시오. **262k 기본 문맥과 512k 확장 지원**도 설정값 존재와 실제 검증된 지원을 구분해야 합니다.

### [4] NVIDIA 공급망 투자·선급금

**확인되는 회계·기술 표현 문제**

- **공급업체 선급금은 NVIDIA의 직접 설비투자와 동일하지 않습니다.** 공급업체가 그 돈으로 설비를 건설하더라도 NVIDIA 입장에서는 선급금·용량 확보 계약 등으로 처리될 수 있습니다. 제목의 “Balance-Sheet CapEx”는 계약 구조와 회계 처리를 확인한 뒤 사용해야 합니다.
- **“300% 증가”는 최종 용량 4배**를 뜻합니다. “기존의 300%로 확대”는 3배입니다. 기사 곳곳의 “300% surge”, “>300% increase”가 원문의 어느 표현을 옮긴 것인지 확인해야 합니다.
- **3년간 2.5배의 CAGR 약 36%는 계산상 맞습니다.** \(2.5^{1/3}-1 \approx 35.7\%\)
- 광엔진 패키징 증설만으로 **Vera Rubin NVL72의 GPU 패키지 인터포저에 광학 연결이 직접 통합된다**고 결론 내릴 수는 없습니다. 네트워크 스위치용 CPO인지, GPU 간 연결용인지 적용 위치를 확인해야 합니다.

**원문 확인 필요**

제공된 [NVIDIA 뉴스룸 URL](https://nvidianews.nvidia.com/news/nvidia-gtc-berlin-supply-chain-commitments-rubin)과 각 협력사 공시에서 다음을 확인해야 합니다.

- KYEC **11억 달러**, 미국 시설 위치와 양산 일정
- IBIDEN 선급금 규모
- 2.5배·300%·15배의 기준 시점 및 적용 공정
- **2,790억 달러 구매약정**의 정확한 SEC 보고서·기준일·항목 범위

**권고:** “경쟁사에 대한 난공불락의 진입장벽”, “공급을 2028년까지 잠갔다”는 표현은 독점성·예약 비중이 확인되지 않으면 완화하십시오. “4배 레티클 이상에서 수율이 지수적으로 하락한다”도 구체적인 공정 자료 없이 일반 법칙처럼 쓰면 안 됩니다.
