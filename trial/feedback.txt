## 1. NVIDIA·Black Forest Labs: 원문 확인과 기술적 표현 수정 필요

### 시간
`2026-11-06`이라는 날짜만으로 `event_within_24h_window: true`를 확정할 수 없습니다. **KST 환산 발표 시각이 11월 6일 10:11 이후인지** 확인해야 합니다. 날짜만으로 위반이라고 단정할 수도 없습니다.

### 초안에서 확인되는 문제

**① 전체 가중치가 SRAM에 들어간다는 설명은 수정해야 합니다.**

> “NVFP4 weights and FP8 attention caches fit within high-speed SRAM”

초안의 5.6B 파라미터가 맞더라도, 4비트 가중치만 단순 계산으로 약 **2.8GB**이며 스케일·메타데이터는 별도입니다. 전체 모델 가중치와 attention 데이터를 온칩 SRAM에 수용한다는 설명은 부적절합니다.

다음처럼 바꾸는 것이 타당합니다.

> 저정밀 가중치로 HBM 사용량과 전송량을 줄이고, 커널 융합·타일링으로 온칩 메모리 재사용을 개선한다.

**② BF16 대비 NVFP4의 가중치 메모리는 단순히 ‘절반’이 아닙니다.**

동일한 파라미터 수를 기준으로 **16비트→4비트의 원시 가중치 저장량은 4분의 1**입니다. 실제 모델 전체 메모리 감소율은 스케일, 비양자화 계층, 활성값 등에 따라 달라집니다. “halving parameter memory footprints”는 비교 기준을 밝혀야 합니다.

**③ 배속만으로 ‘sub-second’를 입증할 수 없습니다.**

3.46배·4.45배는 상대 성능입니다. **기준 지연시간과 최적화 후 절대 지연시간**이 없으면 2048×2048 생성·편집의 1초 미만 달성을 도출할 수 없습니다. 본문과 요약의 “sub-second”는 실측값을 붙이거나 삭제해야 합니다.

### 원문 대조가 필요한 주장
- `FLUX 3 Image Klein`, 5.6B DiT, `Qwen3-VL-4B-Instruct`
- `TensorRT-LLM VisualGen`, `PrimsTS`, `VC-Attention`의 정확한 명칭
- 3.46배·4.45배와 중간 최적화 단계별 수치
- 라이선스, 참조 이미지 10장, repair budget `0.005`
- 단일 B200 실험과 다중 GPU 병렬화 실험의 구분

“비용 65% 이상 절감”, “하드웨어 수명 두 배”도 벤치마크 배속만으로 확정할 수 없습니다. 처리량·품질·가동률·가격 조건을 명시한 **추정 또는 시사점**으로 낮추는 것이 적절합니다.

## 2. CUHK TailSteer: 명확한 시간 위반으로 교체 필요

### 시간 위반
초안 메타데이터가 다음과 같습니다.

- `event_date: 2026-11-05`
- `slot_category: 1-5`
- `event_within_24h_window: false`
- `ongoing_story_exception: false`

따라서 **일반 기사에 적용되는 24시간 조건을 충족하지 않습니다.** 논문이라는 이유만으로 7일 예외가 자동 적용되지는 않습니다. 현재 항목은 슬롯 6이 아닙니다.

`Source Date: 2026-11-06`도 사건 날짜를 갱신하지 않습니다. 11월 6일에 새 체크포인트·코드·벤치마크 등이 실제 공개됐다면 그 **새 개발 사항**을 중심으로 다시 작성하고 정확한 시각과 근거를 제시해야 합니다. 오래된 연구를 소개한 날짜만 최근인 경우에는 예외가 아닙니다.

### 논문 식별자 불일치
동일 항목에 다음이 함께 기재되어 있습니다.

- 주 URL: `arXiv:2611.05377`
- 참조 표기: `arXiv:2611.074xx`

두 표기는 동일한 식별자가 아니며, `074xx`는 완전한 논문 번호도 아닙니다. 이것만으로 논문 자체를 허위라고 단정할 수는 없지만, **현재 인용은 논문을 일관되게 식별하지 못합니다.**

### 내용상 보완
- “drift를 영구적으로 제거”, “untouched background의 정확한 보존”은 제시된 평균 지표만으로 입증되지 않습니다.
- `0% additional FLOPs or VRAM`은 모델 구조·해상도·샘플링 설정을 고정한 비교인지 확인해야 합니다.
- 42~50단계만 학습한다는 설명, 백본 목록, 중간 비교군의 수치와 `+15~35%` 지연 증가는 각각 출처가 필요합니다.

**판정:** 현재 상태에서는 교체·재검색 대상입니다. 최신 신규 발표가 확인된다면 같은 연구를 다시 채택할 여지는 있습니다.

## 3. Tencent WeLM-Image: 아키텍처 설명의 내부 충돌 수정 필요

### 시간
1번과 마찬가지로 **11월 6일의 정확한 발표 시각과 시간대**가 필요합니다.

### 확인되는 문제

**① ‘별도 diffusion decoder 제거’와 구조표가 충돌합니다.**

본문은 별도 vision-language frontend와 diffusion decoder가 필요 없어졌다고 설명하지만, 구조표에는 **생성 경로와 latent autoencoder 출력 계층**이 남아 있습니다.

“이해·생성을 통합한 모델”과 “이미지 디코더가 없는 모델”은 다릅니다. 실제 논문의 구성에 맞춰 다음을 구별해야 합니다.

- 이해·생성 파라미터의 분리 또는 공유
- 공통 attention과 MoE 라우팅
- 잠재공간 생성 백본
- 잠재값을 픽셀로 바꾸는 이미지 디코더

또한 flow matching을 곧바로 autoencoder의 속성으로 표현한 부분도 확인이 필요합니다.

**② 활성 파라미터 수는 저장 메모리 감소와 다릅니다.**

5.4B가 토큰당 활성 파라미터라면 주로 **연산량**에 관한 수치입니다. 전체 31.7B를 BF16으로 저장하면 가중치만 약 **63.4GB**이며, 활성값·작업 공간 등은 별도입니다.

단일 H20 실행 가능성 자체를 반박할 근거는 없지만, 이를 소비자 노트북·스마트폰 배포 효율로 확장해서는 안 됩니다. 또한 “전체 가중치가 반드시 VRAM에 상주해야 한다”는 문장도 오프로딩 등을 제외한 **해당 실행 구성의 조건**으로 한정해야 합니다.

**③ 요약의 단위 오류**
`5.4B active tokens`는 본문의 주장과 다릅니다. **`5.4B active parameters per latent token`**으로 수정해야 합니다.

### 원문 확인이 필요한 사항
31.7B·5.4B, 4.98초, H20, 8단계, MeanFlow, 세 벤치마크 1위는 모두 논문 표·모델 카드와 대조해야 합니다. 순위에는 **평가 버전, 공개 모델 한정 여부, 비교 시점**을 붙이는 것이 필요합니다.

## 4. MPS Dual-Phase DrMOS: 시간 적합, 제품·시스템 수준을 구분해야 함

### 시간
11월 2일 사건은 **슬롯 6의 7일 범위 안**입니다. 24시간 초과를 이유로 교체할 항목이 아닙니다.

### 보완 사항

**① 듀얼페이즈 패키지와 단일 실리콘 다이는 동일하지 않습니다.**

두 전력단을 하나의 패키지에 넣었다는 설명만으로 다음을 도출할 수 없습니다.

> “two complete driver-MOSFET stages into a monolithic silicon die”  
> “eliminates inter-die bond wires”

제품 데이터시트나 단면·공정 설명으로 확인하기 전에는 **“단일 패키지 내 듀얼페이즈 통합”**으로 제한해야 합니다.

**② 60A+60A와 TDC 25A+25A의 비교 조건이 필요합니다.**

두 수치는 정격 정의와 열 조건이 다를 수 있으므로 자체 모순이라고 단정할 수는 없습니다. 다만 100A 단일페이즈와 면적을 비교하려면 다음을 맞춰야 합니다.

- 동일한 연속 출력전류와 냉각 조건
- 입력·출력전압, 스위칭 주파수
- 허용 접합온도
- 인덕터·커패시터를 포함하는 면적 범위

표의 `112mm→56mm`는 **길이 비교**이므로, 이것만으로 전체 실장 면적이 50% 감소했다고 확정할 수 없습니다.

**③ 시스템 효과를 과도하게 확장했습니다.**

듀얼페이즈 패키징만으로 PCB 층수 감소, MLCC 수량 감소, 직접 액체냉각 필수, 특정 고객 설계 채택을 확정할 수 없습니다. 이들은 보드 설계·열 설계·고객 채택 근거가 필요한 별도 주장입니다.

1,000~2,000A는 **다수 전력단으로 구성된 소켓 전원 레일 수준**의 값이며, 단일 MP87563의 공급 능력처럼 읽히지 않도록 구분해야 합니다.
