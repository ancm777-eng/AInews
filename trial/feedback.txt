**현재 초안은 즉시 발행하기 어렵습니다.** 다만, 제공된 자료만으로 특정 기사의 핵심 발표가 허위이거나 시간 윈도우를 위반했다고 확정할 근거도 부족합니다. 확인되지 않은 내용을 허위로 판정하지 않고, **검증 보류 사항과 명확한 논리·수치 문제를 구분**했습니다.

**검증 범위의 한계:** 이 대화에서는 실시간 웹 검색이나 URL 접속 도구가 제공되지 않았습니다. 따라서 아래 URL의 실제 응답, 모델 카드, 발표 원문, 벤치마크 이력 등을 외부 자료와 교차 확인했다고 주장할 수 없습니다. 아래 판정은 **제공된 초안의 내부 정합성과 확인 가능한 계산·기술적 해석에 근거한 편집 판정**입니다.

## 2. 기사별 사실·논리 검토

### ① Bria Fibo 2.0 — 수치의 의미와 법적·하드웨어 해석 수정 필요

**명확히 수정할 부분**

- **“16GB GPU에 적합”이라는 결론은 제시된 수치와 맞지 않습니다.**  
  초안 자체가 FP16 메모리를 약 16.8GB로 제시하면서 RTX 4080 16GB를 적합한 장비로 포함합니다. 추가로 텍스트 인코더, VAE, 활성값, 참조 이미지 등에 메모리가 필요할 수 있습니다.  
  → “16GB에서는 양자화·CPU 오프로딩 등 조건 확인 필요, 24GB에서도 실행 설정별 실측 필요”로 수정하십시오.

- **구조화된 JSON 제어와 결정론적 편집은 다릅니다.**  
  VGL이 속성 지정과 편집 제어를 개선하더라도, 그것만으로 동일 결과 재현이나 비편집 영역의 완전한 보존이 입증되지는 않습니다.  
  → 비교표의 `Deterministic Editing`을 **“구조화된 편집 제어”**로 바꾸는 것이 정확합니다.

- **라이선스 데이터·면책 제공을 법적 위험 제거로 확대했습니다.**  
  “without IP infringement liabilities”는 지나친 단정입니다. 면책에는 계약 대상, 적용 범위, 예외 및 한도가 있을 수 있습니다.  
  → “계약 조건에 따라 일부 지식재산권 위험을 완화할 수 있다”로 수정하십시오.

- **순위 범위를 명확히 해야 합니다.**  
  본문은 “오픈웨이트 중 1위”인데 제목의 “Tops … Arena”는 전체 모델 1위로 읽힙니다.  
  → 제목에도 **“오픈웨이트 부문”**을 명시하십시오.

**원문 확인이 필요한 핵심 주장**

- `https://huggingface.co/briaai/Fibo-2.0-dev`의 실제 모델 카드·공개 이력
- 8B, Edit Turbo 4스텝, CC BY-NC 4.0의 체크포인트별 적용 여부
- Elo 1087 및 생성 부문 2위의 기준 시각·비교 집단
- Diffusers PR #14991의 대상 모델과 **병합 여부**
- fal.ai 및 공식 ComfyUI 통합의 실제 공개 상태
- 비교 대상으로 등장하는 `Nano Banana 2.1`, `GPT-Image 2.5 Sunburst`의 공식 명칭

“최초의 통합 아키텍처”와 특정 텍스처·커닝 열화 평가도 각각 선행 모델 비교와 테스트 근거가 필요합니다.

### ② FastH3 Omni — 스텝 감소를 연산량·실행시간 감소로 등치한 부분 수정 필요

**명확히 수정할 부분**

- **84%는 스텝 수 감소율입니다.**  
  계산 자체는 맞습니다.
  \[
  (50-8)/50=84\%
  \]
  그러나 이것이 곧 **전체 연산량 또는 비용 84% 감소**를 뜻하지는 않습니다. 스텝당 비용과 인코딩·디코딩 비용 등이 같다는 조건이 필요합니다.  
  → “50스텝 대비 샘플링 스텝 수 84% 감소”로 제한하십시오.

- **“RTX 4090 또는 A100/H100에서 15초 미만”은 벤치마크 조건이 빠져 있습니다.**  
  출력 해상도·길이·정밀도·참조 수·GPU 수가 없으므로 재현할 수 없습니다. 서로 다른 GPU를 한데 묶은 표현도 부적절합니다.  
  → 조건별 실측을 제시하거나 시간을 삭제하십시오.

- **참조 개수는 모순으로 단정할 수 없지만 설명이 필요합니다.**  
  이미지 9개·영상 3개·음성 3개의 종류별 상한 합계는 15개입니다. 그러나 **전체 상한 12개와 종류별 상한이 동시에 적용되는 구조**라면 모순이 아닙니다.  
  → “총 12개 이하이며, 종류별로 각각 9·3·3개 이하”인지 확인해 명시하십시오.

- **프레임 수와 길이 표기를 통일해야 합니다.**  
  단순히 프레임 수를 24fps로 나누면 124·243·362프레임은 약 **5.17·10.13·15.08초**입니다. “5·10·15초”는 명목 프리셋인지 구분해야 합니다.

**가장 우선적으로 확인할 핵심 사실**

제시된 URL은 **FastVideo 저장소 전체 주소**이지 해당 모델 발표를 직접 가리키는 주소가 아닙니다. 다음을 확인할 릴리스·커밋·모델 카드가 필요합니다.

- `FastH3 Omni`의 정확한 모델명과 발표 주체
- **“MiniMax H3 기반”이라는 계보**
- 8스텝, 공동 영상·음성 생성, 32kHz 스테레오
- BF16·FP8 체크포인트와 ComfyUI 지원

현재 자료만으로 이 계보를 허위로 단정하지는 않지만, 기사 핵심이므로 확인 전 발행해서는 안 됩니다.

### ③ Runway–Claude Marketplace — 유통 제휴와 기술 통합을 분리해야 함

**가장 중요한 문제는 서로 다른 주장이 하나의 발표처럼 묶여 있다는 점입니다.**

다음은 각각 별도 증거가 필요한 사실입니다.

1. Runway의 Claude Marketplace 입점
2. `Runway Creative`의 실제 상품명·제공 범위
3. Anthropic 공식 제품으로서의 `Claude Motion`
4. Claude Motion에서 Runway로 이어지는 직접 제작·내보내기 기능
5. Anthropic 약정 지출의 Runway 구매 적용
6. Claude Team·Enterprise 대상 전 세계 제공

**마켓플레이스 입점이 확인되더라도, 나머지가 자동으로 입증되는 것은 아닙니다.**

**수정·보완 사항**

- “Anthropic 클라우드 약정”, “플랫폼 크레딧”, “실시간 정산”을 같은 의미로 쓰지 마십시오. 구매 약정과 API 사용 크레딧은 계약상 다를 수 있습니다.
- `Seedance 2.5`, `Kling 3.0`, `ElevenLabs V4`, `Aleph 2.0`이 **그 통합 상품에서 실제로 지원되는지** 공식 목록이 필요합니다.
- Amazon·Robinhood·Microsoft를 **해당 상품의 출시 파트너**로 부를 직접 근거가 필요합니다.
- 코드·벡터 결과물을 가져오는 기능이 있다는 것과, 카메라 궤적·레이아웃이 확산 모델의 조건으로 직접 들어간다는 것은 별개입니다.

제시된 `https://runwayml.com/news/runway-joins-claude-marketplace` 원문에서 위 내용을 문장별로 대조해야 합니다. 입점만 확인된다면 **기사 교체보다는 조달·유통 제휴 중심으로 재작성**할 수 있습니다.

### ④ NVIDIA OOI — 7일 예외 적용 가능, 연구 성능·상용화 전망 분리 필요

**시간상 교체 사유는 없습니다.** 다만 다음 표현은 수정해야 합니다.

- **HBM을 일반적인 “캐시”로 표기하지 마십시오.**  
  표의 “Local high-bandwidth memory cache”는 **“고대역폭 디바이스 메모리”**로 수정하는 것이 적절합니다.

- **256Gb/s는 산술적으로 맞지만 대역폭의 정의가 필요합니다.**  
  8파장 × 32Gb/s = 256Gb/s입니다. 다만 원시 선로 속도인지, 오류정정·프로토콜 오버헤드를 제외한 유효 속도인지, 단방향인지 명시해야 합니다.

- **“전력 60~70% 절감”은 비교 기준이 없습니다.**  
  전기 I/O 회로, 광 링크, 전체 패키지, 랙 전체 중 어느 범위의 전력인지 구분해야 합니다. 실측·시뮬레이션·작성자 추정 여부도 표시하십시오.

- **“광 채널 하나가 고장 나면 전체 패키지가 사용 불능”은 과도한 일반화입니다.**  
  외부 레이저, 예비 채널, 장애 격리, 수리 가능성 등에 따라 결과가 달라집니다. 특히 초안은 레이저를 외부 부품으로도 설명합니다.  
  → “일부 통합 광소자의 결함은 패키지 수율과 교체 비용을 악화시킬 수 있다”로 수정하십시오.

**직접 확인이 필요한 주장**

- Nikola Nedovic의 직함·발표 내용·실제 발표일
- OOI와 8파장 DWDM 실증이 동일 발표·시제품에 관한 것인지
- `<2mm`, `sub-1V`, 60~70%의 출처
- TSMC COUPE, SPIL, Coherent/Lumentum, Corning/Senko가 **해당 시제품**의 참여사인지
- “2027년 이후 상용화”가 공식 계획인지 작성자 전망인지

Wccftech 기사의 게시일만으로 연구 공개일을 확정하지 말고, 발표 슬라이드·연구 문헌·행사 기록으로 확인해야 합니다.

## 3. 요약·행사 일정의 추가 수정

- **“8스텝이 실시간 로컬 영상 제작을 입증했다”**는 결론은 현재 제시된 정보로 뒷받침되지 않습니다.

- `RTX Spark`는 제품명 확인이 필요합니다. 유사 명칭의 제품을 추정해 대체해서는 안 됩니다.
- IEDM·DesignCon의 날짜와 개최지도 공식 행사 페이지 확인 전 확정적으로 게재하지 않는 편이 안전합니다.
