2. **LM Studio/Ollama와 vLLM 관계를 뭉뚱그림**
   - Ollama와 LM Studio가 일반적으로 llama.cpp 계열 및 각 플랫폼별 엔진을 활용하는 것과, vLLM을 이들의 “로컬 런타임”으로 기본 지원한다는 것은 별개입니다.
   - 특히 Apple Silicon 지원을 설명하면서 vLLM까지 동일 계층으로 묶으려면 공식 호환성 표가 필요합니다.

3. **IFA 개막일과 발표 표현**
   - 캘린더상 IFA 2026은 9월 4일 개막으로 쓰면서 본문은 9월 3일 “at IFA 2026”이라고 합니다.
   - 9월 3일이 프레스 데이였다면 “IFA 개막 전 프레스 행사에서”라고 정확히 표현해야 합니다.

4. **성능 수치 자체의 산술**
   - 18분에서 8분 48초로 줄었다면 시간 감소율은 약 **51.1%**입니다.
   - 처리량 비율은 약 **2.05배**이므로 “실행시간 50% 이상 감소”와 “처리량 두 배 이상”은 산술적으로는 맞습니다.
   - 하지만 모델, 프롬프트 크기, 장치 구성, 순차·병렬 실행 조건이 없으므로 일반 성능 주장으로 확대할 수 없습니다.

## 4. Samsung Electro-Mechanics 유리 코어 기판 로드맵

### 판정: **부분적으로 타당한 산업 배경이나, 발표 사실과 정량 사양은 검증 미흡**

행사 프로그램 URL만으로는 이 모든 기술 사양을 입증할 수 없습니다. 발표 슬라이드, 초록, SEMCO 보도자료 또는 발표자 인터뷰가 별도로 필요합니다.

### 명확한 기술 오류·과장

1. **“ABF core” 표현**
   - ABF는 일반적으로 빌드업 절연재를 가리킵니다.
   - 유기 코어와 그 위의 ABF 빌드업층을 구분해야 하므로 `organic ABF core substrate` 또는 “ABF core를 유리가 대체한다”는 표현은 부정확합니다.
   - “유기 코어를 유리 코어로 대체하되 빌드업 절연층은 별도로 구성”하는 식으로 설명해야 합니다.

2. **유리가 리타이머를 없앤다는 인과관계**
   - 패키지 기판의 삽입손실 개선만으로 가속기 캐리어 보드상의 리타이머가 자동으로 불필요해지는 것은 아닙니다.
   - 리타이머 필요성은 전체 채널 길이, PCB 재료, 커넥터, 손실 예산 및 SerDes 규격에 달려 있습니다.
   - “리타이머 의존도를 낮출 잠재력이 있다” 정도로 완화해야 합니다.

3. **“warpage를 eliminate”**
   - 유리는 휨을 줄일 수 있지만, 빌드업층 비대칭, 구리 밀도, 접합재와 열팽창 차이로 인한 휨을 완전히 제거하지는 못합니다.
   - `reduce/suppress`가 적절합니다.

4. **“4배 수직 배선 밀도”**
   - 비교 기준 피치와 면적 밀도 계산이 없습니다. 선형 피치가 절반이면 이론적 면적 밀도는 4배가 될 수 있지만, 초안은 기준값을 제시하지 않았습니다.

5. **Glass Dk/Df의 단순화**
   - 유리는 조성에 따라 특성이 달라지고, Dk가 항상 유기재보다 낮은 것도 아닙니다.
   - 주파수, 측정법, 유리 조성을 함께 밝혀야 합니다.

6. **Phase 1 “Active Production”**
   - 이것이 SEMCO의 특정 제품 로드맵인지 업계 일반 상태인지 불분명합니다.
   - 회사 공식 로드맵처럼 표기하려면 발표 슬라이드 근거가 필요합니다.

|---|---|
| `openai.com/index/gpt-6-astra/` | 해당 제품의 유효한 공식 발표 근거로 확인되지 않음 |
| `artificialanalysis.ai/models/frontier-comparison-astra-flash-fable` | 해당 비교 기사의 신뢰 가능한 원문으로 확인되지 않음 |
| `developer.nvidia.com/blog/nvidia-pair-virtual-inference-router/` | 해당 NVIDIA 공식 제품 발표로 확인되지 않음 |
| `semicontaiwan.org/en/programs/strategic-materials-conference-2026` | 행사 프로그램 성격의 URL일 수 있으나, 본문에 열거된 SEMCO 정량 사양 전체를 뒷받침하지 않음 |

각 URL은 실제 HTTP 상태뿐 아니라 **페이지 제목, 발행일, 저자, 본문에 해당 수치가 존재하는지**까지 검증해야 합니다. URL 문자열이 공식 도메인 형식을 취한다는 것만으로 1차 자료가 되지 않습니다.

## 최종 편집 권고

1. **1번 삭제:** 공식 발표·시스템 카드가 확인되지 않는 한 전면 삭제.
2. **2번 삭제 또는 전면 재작성:** 세 모델의 공식 존재와 가격표가 확인된 뒤 동일 평가 조건으로 다시 비교.
3. **3번 삭제:** NVIDIA 공식 블로그 및 GitHub 저장소를 확인할 때까지 출시 기사로 사용 금지.
4. **4번 보류:** 행사 발표자료나 SEMCO 원문을 확보한 뒤 정량 사양과 로드맵만 제한적으로 복원.
5. Executive Summary와 최종 Synthesis도 1~3번의 미검증 주장을 그대로 반복하므로 함께 삭제해야 합니다.
6. 시간 윈도우 메타데이터는 대체로 맞지만, **시간 내 게시되었다는 사실은 내용의 진위를 보증하지 않습니다.**

따라서 이 초안은 “몇몇 수치 수정” 수준이 아니라 **출처 원문을 다시 수집하여 전체를 재작성해야 하는 상태**입니다.
