## 2. 기사별 사실·논리 검증

### ① fal / Black Forest Labs — FLUX 3 Max

**명확히 수정할 부분**

- **속도 배율의 비교 기준이 일치하지 않습니다.**
  - `277.8 ÷ 12.45 = 약 22.3배`
  - `277.8 ÷ 10.95 = 약 25.4배`
  
  본문에 제시한 22.3배는 **12.45초 기준**으로는 맞지만, 비교표의 10.95초와 결합하면 맞지 않습니다. 측정 조건을 통일하거나 “약 22.3∼25.4배”로 구분해야 합니다.

- **“실시간”과 “실시간에 근접한 생성”을 구분해야 합니다.** 10초 영상을 10.95∼12.45초에 생성하면 생성 속도는 약 **0.80∼0.91배 실시간**입니다. “재생 길이에 근접한 생성 시간”은 가능하지만, 이 수치만으로 실시간 스트리밍·프레임별 상호작용까지 입증되지는 않습니다.

- **신뢰구간 중첩으로 특정 영상 결함을 설명할 수 없습니다.** Elo 신뢰구간의 중첩은 순위 불확실성과 관계가 있을 뿐, 다인 충돌이나 움직이는 텍스트의 왜곡을 입증하지 않습니다. 해당 결함에는 별도 평가 출처가 필요합니다.

**원문 확인이 필요한 핵심 주장**

- fal과 Black Forest Labs의 공동 발표 및 정확한 제품명
- Artificial Analysis의 평가 부문, 기준 시각, Elo·투표 수
- 해상도·프레임 수·음성·큐 대기 포함 여부가 같은 속도 비교인지
- 증류, FP8 캐싱, speculative denoising 등 실제 구현 기술
- H100/H200·Blackwell 사용 및 GPU 계산량 95% 감소

특히 **응답 지연 감소가 GPU-hours 감소와 같은 것은 아닙니다.** 병렬 GPU 사용량이 늘어도 지연은 줄어들 수 있습니다. 또한 **판매가 $0.04/초만으로 공급자의 원가나 마진을 추정할 수 없습니다.**

비교표의 MiniMax 점수가 1,140으로 더 높은 점도 확인해야 합니다. 통계적 공동 선두라면 “단독 1위”가 아니라 **공동 선두권**이라고 표현하는 편이 정확합니다.

**권고:** 주제는 유지하되, 속도 비교 조건과 순위 표현을 수정하고 미확인 구현 세부사항은 삭제하거나 출처를 붙이십시오.

### ② MiniMax — M3.1 Flash / Space Bunny

**명확히 수정할 부분**

- **토큰 비용의 분모가 혼동됩니다.** 입력 100만 토큰 $0.15와 출력 100만 토큰 $0.60을 더한 $0.75는 **총 200만 토큰 작업의 비용**입니다. 이를 “blended 1M”으로 표기하면 부정확합니다. 입력·출력 비율이 1:1인 총 100만 토큰 비용은 **$0.375**입니다.

- **MoE 활성 파라미터와 KV 캐시를 직접 연결한 설명은 과도합니다.** 활성 파라미터가 적으면 토큰당 연산량을 줄일 수 있지만, 전체 가중치 상주 메모리, 전문가 통신, KV 캐시 용량·대역폭까지 같은 비율로 줄어드는 것은 아닙니다. KV 캐시는 별도 attention 구조와 문맥 길이 조건으로 설명해야 합니다.

- **자체 비교표로는 가격 우위를 일반화하기 어렵습니다.** 표에 제시된 GPT-6 Luna 가격은 입력·출력 모두 M3.1 Flash보다 낮습니다. 따라서 가격 충격의 대상과 비교 범위를 특정해야 합니다. 이는 GPT-6 Luna의 실재·가격을 확인했다는 뜻은 아닙니다.

**원문 확인이 필요한 핵심 주장**

- 428B/23B, 100만 문맥, 시각 인코더 및 추론 단계 설정
- 200조 토큰의 **집계 기간·대상·단위**
- Automation-Bench·BankerToolBench·Terminal Bench의 정확한 명칭과 버전
- 10월 23일 가중치 공개 일정 및 라이선스

100 tok/s와 TTFT 1.22초도 입력 길이·출력 길이·동시성·추론 설정 없이 보편적 성능처럼 제시하면 안 됩니다.

**권고:** 모델 카드, API 가격표, OpenRouter 모델 페이지를 각각 연결하고, 확인되지 않은 공개 일정은 달력에서도 제거하거나 “예정·공식 확인 필요”로 표시하십시오.

### ③ Krea — Krea 3 / ComfyUI

**수정·한정할 부분**

- **“1,000장을 2시간 이내”는 현재 정보로 보장되지 않습니다.** 장당 8초를 적용하면 직렬 처리 시간은 **8,000초, 즉 2시간 13분 20초**입니다. “8초 미만”에는 7.2초보다 빠른 경우도 포함되므로 명백한 모순은 아니지만, 해당 결론에는 평균 지연이나 병렬 처리 조건이 필요합니다.

- **“정액 $0.06”과 최대 $0.13 과금을 구분해야 합니다.** 기본 출력 요금이 $0.06이고 참조 이미지 처리에 추가 비용이 붙는 구조라면 양립 가능합니다. 다만 전체 요청에 적용되는 정액처럼 서술하면 오해를 줍니다.

- **공간 제어가 픽셀 보존을 보장하지는 않습니다.** 바운딩 박스·참조 이미지·LoRA 지원만으로 비편집 영역의 완전한 픽셀 보존이나 결정론적 결과가 입증되지는 않습니다. 공식 보장 범위나 평가 결과가 필요합니다.

### ④ Celestica — DS6005 / Broadcom CPO

**내부 계산상 일치하는 부분**

- `64 × 1.6 Tbps = 102.4 Tbps`
- `512 × 200 Gbps = 102.4 Tbps`

다만 이것이 외부 제품 사양을 검증한 것은 아닙니다.

**명확히 수정할 부분**

- **대역폭 2배가 radix 2배를 뜻하지 않습니다.** 기존 51.2 Tbps 스위치가 64×800G였다면 64×1.6T로 전환해도 포트 수는 같습니다. “radix와 대역폭 밀도를 모두 두 배”라는 문구는 비교 대상의 포트 구성이 있어야 성립합니다.

- **“100% 액체냉각”과 전력·냉각 수치는 구분해야 합니다.** 46∼56V, 최대 76A는 계산상 약 3.50∼4.26kW의 입력 범위에 해당하지만, 최대 정격을 실제 소비전력이나 냉각 부하로 해석해서는 안 됩니다. `>1,500W`도 냉각 대상과 시험 조건을 명시해야 합니다.

**원문 확인이 필요한 핵심 주장**

- DS6005, BCM78919, Tomahawk 6–Davisson의 정확한 대응 관계
- 3nm 공정, 1.5OU, ELSFP·MMC-16 수량과 광 인터페이스 구성
- 무팬·전면 액체냉각 여부와 SONiC 지원
- 2027년 초 상용 배치 일정

CPO가 **전면 광모듈의 DSP를 제거하는 것**과 **모든 DSP·리타이밍 기능이 사라지는 것**은 다릅니다. 또한 광엔진 고장 시 전체 스위치를 반드시 교체해야 한다는 주장도 실제 서비스 모듈 경계에 따라 달라집니다.

**권고:** 기술 시연·샘플링 단계라면 “상용 산업화를 입증했다”보다 **“상용화 아키텍처를 제시했다”**가 적절합니다.

## 3. URL·출처 및 종합 섹션 보완

제시된 URL의 도메인이 해당 매체나 기업 형태와 부합한다는 것만으로 **문서 존재·게시일·본문 내용이 검증되지는 않습니다.** 현재 네 개 Primary URL의 접속 가능 여부와 내용을 확인했다고 말할 수 없습니다.

발행 전에는 다음이 필요합니다.

1. **각 기사 원문의 게시 시각과 시간대** 확인  
2. 발표문·모델 카드·가격표·벤치마크·제품 사양서의 **개별 URL** 확보  
3. 홈페이지 주소만 달린 수치를 실제 해당 문서로 교체  
4. 실측 사실과 전망을 분리하고, 확인되지 않은 아키텍처 설명 삭제  
5. 종합 전망과 기술 일정에서도 동일한 미확인 수치·공개일을 정리  

또한 전망의 **“USFP standard”**는 정확한 규격명인지 확인해야 합니다. 본문의 OSFP와 다른 용어이므로 의도한 커넥터·모듈 규격을 특정하십시오.

**최종 판단:** 확인 가능한 산술·논리 문제는 기사 교체 없이 수정할 수 있습니다. 제공 자료만으로 핵심 사실의 허위나 시간 초과를 확정할 근거는 없으므로 전면 교체 판정은 하지 않습니다. 다만 아래 판정은 **주제 실재성에 대한 외부 검증 완료나 발행 승인을 의미하지 않으며**, 원문 확인을 전제로 한 보완 판정입니다.
