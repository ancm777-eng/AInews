    1. Executive Summary

    Hyperscale data centers serving large language models are confronting a critical memory wall, as multi-turn conversational contexts quickly saturate on-package High Bandwidth Memory and leave high-cost GPU tensor cores underutilized. Marvell mitigates this infrastructure bottleneck by detailing its second-generation Structera X 3406/3506 memory expansion controllers, fabricated on a 5nm process and supporting six CXL 3.2 memory channels over a PCIe 6.0 physical layer. By integrating a dedicated hardware compression engine that delivers 250 GB/s inline LZ4 throughput, Structera X expands server memory capacity up to 9TB while cutting Time to First Token by up to 50%.

    CXL 3.2: An open interconnect standard utilizing PCIe physical layers to provide coherent memory sharing and dynamic memory pooling across multiple host processors.

    PAM4 Signaling: Four-level Pulse Amplitude Modulation encoding two bits per cycle, enabling 64 GT/s per lane transfer rates in PCIe 6.0 architectures.

    Inline Compression: Hardware pipeline that compresses and decompresses memory blocks in real time over the bus, minimizing host processor overhead.
