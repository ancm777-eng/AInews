    Anthropic Releases sandbox-runtime (srt): Containerless Process Sandboxing for MCP Agents

    1. Executive Summary

    Autonomous coding agents require local terminal access to inspect files and execute scripts, yet standard deployments force security teams to choose between vulnerability to prompt injection or the severe latency and memory penalties of virtual machines. Anthropic resolves this operational compromise by open-sourcing sandbox-runtime (srt), an Apache 2.0-licensed framework extracted from Claude Code. Operating directly at the native OS layer via Apple Seatbelt profiles on macOS and bubblewrap network unsharing on Linux, srt confines agent processes without Docker daemons or hypervisor overhead.     2. Architecture & Performance

    Rather than spinning up guest kernels, srt leverages granular operating-system confinement primitives that apply dynamically generated security manifests directly to child process forks. Outbound network traffic is intercepted by dual host-level HTTP and SOCKS5 proxies that validate external calls against cryptographically signed domain allowlists.
