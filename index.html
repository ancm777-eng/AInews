    Tenstorrent Galaxy: Modular GDDR6 Clusters Unlock 2x Memory-per-Dollar Advantage

    1. Executive Summary

    Large-model inference economics suffer from escalating capital expenditure driven by scarce High Bandwidth Memory (HBM3/e) and complex 2.5D packaging bottlenecks like TSMC CoWoS. Tenstorrent resolves this cost scaling barrier in its evaluation of the Galaxy Blackhole cluster, interconnecting 32 modular accelerators over a unified direct 2D-torus network. By deploying standard GDDR6 memory packages (32 GB per socket, 512 GB/s) paired with 210 MB of on-chip SRAM and RISC-V Tensix cores, the architecture achieves 102 GB/s memory bandwidth and 6.4 GB capacity per $1,000—yielding a 2x memory-per-dollar advantage over premier HBM GPU servers. This modular topology provides hyperscalers with an accessible hardware path for memory-bound token decoding without competing for high-density silicon interposer packaging allocations.

    Key Architecture Concepts:

    • Tensix Matrix Engines: Proprietary RISC-V compute cores optimized for block FP8 matrix execution and dynamic communication packet scheduling.
    • Direct Torus Fabric: Native board-level differential signaling interconnect connecting chips in pipelined rings without external PCIe switches.
    • CoWoS-Free Packaging: Mounting standard GDDR6 DRAM onto standard organic printed substrates, bypassing high-density silicon interposer supply chains.
