    Register-Transfer Level (RTL): A high-level hardware description abstraction (e.g., SystemVerilog) modeling synchronous digital circuit dataflow between hardware registers and combinational logic.

    2. Architecture & Performance

    Generic foundation models lack awareness of cell libraries, physical interconnect parasitics, and static timing constraints, routinely producing syntactically correct code that fails gate-level synthesis. The ChipStack RTL Generation Agent resolves this disconnect by establishing a closed-loop iterative pipeline where generated code is synthesized in real time, evaluated for Worst Negative Slack (WNS), cell switching capacitance, and gate congestion, and refactored autonomously prior to physical signoff.
