    NVIDIA Nemotron 3.5 Bolt: Compressing 74B MoE to 2-Bit Sub-20GB Weights for Edge Execution

    1. Executive Summary

    Frontier multi-step agent reasoning has historically remained locked in hyperscale cloud clusters because 70B+ parameter models cannot fit into consumer hardware without catastrophic quantization degradation. NVIDIA breaks this memory barrier with Nemotron 3.5 Bolt 74B-A9B, a hybrid Mamba-Transformer Mixture-of-Experts architecture compressed via native 2.0625-bit IQ2-XXS quantization and Quantization-Aware Distillation. This extreme compression shrinks the raw model weight footprint to 19.08 GB, allowing local execution within a standard 24 GB unified memory footprint at inference speeds up to 84 tokens per second on client-class edge silicon.

    2. Architecture & Performance

    The Nemotron 3.5 Bolt model decouples parameter scale from operational memory bandwidth by coupling a sparse routing mechanism—activating only 9 billion parameters per token out of 74 billion total—with the Star Elastic compression pipeline. The hybrid Mamba-Transformer backbone replaces standard attention layers with linear state-space formulations for sequence processing, mitigating the quadratic KV-cache memory penalty during sustained multi-turn agent execution.

    Microsoft Unveils Maia 300 AI Accelerator: TSMC 2nm/3nm Multi-Chiplet Architecture with 18 TB/s HBM4 and 167 kW Direct Liquid-Cooled Enclosures

    1. Executive Summary

    Hyperscale inference economics are increasingly constrained by the exorbitant capital costs and thermal limits of general-purpose monolithic GPUs running memory-bandwidth-bound model architectures. Microsoft overcomes these operational limits with the custom Maia 300, integrating TSMC 2nm N2P compute dies and 3nm I/O dies with 288 GB of HBM4 memory on an advanced 2.5D silicon interposer. Delivering an industry-leading 18.0 TB/s per-accelerator bandwidth in a 167 kW liquid-cooled rack housing 96 processors, the system projects a 40% efficiency gain in tokens per megawatt alongside a 7x throughput multiplication over Maia 200.

    Key Architectural Concepts:
    • 2.5D Disaggregated Chiplet Assembly: Decoupling advanced compute cores (TSMC 2nm N2P) from cost-optimized I/O and routing fabric (TSMC 3nm) using micro-bump interconnects on an active silicon substrate.
    • HBM4 2048-Bit Interface: Next-generation high-bandwidth memory standard doubling bus width over HBM3e to achieve 18.0 TB/s throughput directly adjacent to the compute engines.
    • Direct-to-Chip (D2C) Liquid Cooling: Closed-loop thermal management circulating dielectric coolant directly through micro-channel cold plates to dissipate 167 kW per rack enclosure.

    2. Architecture & Performance

    The Maia 300 disaggregates compute execution from protocol transport by fabricating core tensor engines on the high-performance TSMC 2nm N2P node, while routing interfaces reside on proven 3nm silicon to optimize structural wafer yields. Memory bottlenecks are addressed through eight integrated HBM4 stacks linked via a wide 2048-bit bus, providing 288 GB local capacity supported by a 272 MB software-managed on-chip SRAM scratchpad.
